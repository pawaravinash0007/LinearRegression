## 📖 Overview

A thorough implementation of **Linear Regression** — the foundational supervised learning algorithm for continuous value prediction. Covers simple and multiple linear regression, from mathematical derivation to practical implementation.

---

## 🎯 Topics Covered

- Simple Linear Regression (one feature)
- Multiple Linear Regression (multiple features)
- Ordinary Least Squares (OLS) derivation
- Gradient Descent optimization
- Regularization: Ridge (L2) and Lasso (L1)
- Polynomial Regression
- Evaluation: MSE, RMSE, MAE, R²
